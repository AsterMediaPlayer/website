Anime openings and endings

For Jellyfin servers · Aster OP-ED plugin 0.5

In short: put your opening and ending files in a folder on your Jellyfin server, one folder per show. The free Aster OP-ED plugin matches each one to the right episodes and fills in the song and artist, and Aster plays them from the episode page.

What works without the plugin

With no plugin on your server, Aster looks for opening and ending chapter markers in your episodes. When it finds them, Watch OP and Watch ED play that part of the episode. This works with any Jellyfin server, as long as your files have chapters.

The plugin adds everything else on this page: song titles and artists, the episodes each theme aired with, full-length songs, music videos, theme libraries, and cutting missing themes out of your episodes.

Install the plugin

You need Jellyfin 12 and an administrator account.

  1. In Jellyfin, open Dashboard ▸ Plugins ▸ Repositories and add this repository: https://raw.githubusercontent.com/AsterMediaPlayer/aster-companion-plugins/main/manifest.json
  2. Open the Catalogue, find Aster OP-ED under Metadata, and install it.
  3. Restart Jellyfin.
  4. Open Dashboard ▸ Aster OP/ED and choose your themes folder, as below.

If you're signed in to Aster as a Jellyfin administrator, Aster can also install the plugin for you.

Set up your themes folder

On the Setup tab, choose the folder your theme files will live in. Two rules:

  • Give the path as Jellyfin sees it. If Jellyfin runs in Docker, that's the path inside the container, not on your computer.
  • Keep it outside your library folders, so Jellyfin doesn't scan the themes as ordinary videos.

Inside it, make one folder per show, named exactly like that show's folder in your library:

anime_themes/ Frieren (2023)/ OP1.webm OP1.ogg ED1.webm Season 2/ OP1.webm anidb-18886/ ED2.webm
  • One theme, two files. A video and an audio file with the same name, like OP1.webm and OP1.ogg, are one theme.
  • Seasons. Files directly in the show's folder can apply to the whole show. Put them in a Season 2 folder to tie them to that season, or in an anidb- folder with the AniDB id to tie them to that exact entry.
  • Shokofin. If you use Shokofin, whose library folders are virtual, name the show folders after your original files' folders. The plugin follows each episode back to its real file.

Naming theme files

A theme file's name starts with OP or ED, then an optional number. Anything the plugin doesn't need, such as NCBD1080, is ignored, so AnimeThemes' own file names work as they are.

NameWhat it is
OP1.webmThe first opening. ED2 is the second ending, and plain OP works when there's only one.
OP1v2.webmA second version of OP1, for example with different footage.
ED1-TV.oggA variant, attached with a hyphen.
OP1-Full.m4a

The full-length song. It belongs to OP1 and shares its song details, so Aster can offer either version.

Also recognised: OP1 Full, OP1 (Full), OP1 [Full Version], OP1 - Full - YOASOBI.

OP1-MV.mp4

The song's official music video. It also belongs to OP1.

Also recognised: OP1 (Music Video), OP1 [MV], OP1 - MV - YOASOBI.

SousouNoFrieren-ED1-TV-NCBD1080.oggAn AnimeThemes download, as it comes.
  • A theme can have a TV-size version, a full version and a music video all at once. Each of them can be video, audio or both.
  • Video: WebM, MP4, MKV, M4V, MOV. Audio: Ogg, Opus, MP3, FLAC, M4A, AAC, WAV.
  • Formats Apple devices can't play, like AnimeThemes' WebM and Ogg, are fine. The plugin makes a playable copy on your server automatically.
  • You can also put the song details in the name: see Song details.

Scanning

The plugin scans the themes folder when Jellyfin starts and every 12 hours. To scan straight away, press Save and scan now on the Setup tab.

After each scan, the Setup tab lists anything it couldn't use: folders that match no show, files that don't look like an opening or ending, and themes with no song details. Check there first when something's missing.

Song details

Each theme can have a song title, artists, the episodes it plays in, and spoiler and NSFW flags. They come from three places, and the most specific one wins, one detail at a time:

1. Your own edits

Open the Library tab in Dashboard ▸ Aster OP/ED. Themes are grouped by show, and you can search, or filter to the ones that need details. Edit a theme to see its details and where each came from, then Save. Clear removes your edit, so the other sources apply again. Jellyfin needs permission to write to the themes folder for this.

Your edits are saved in a themes.json file in the show's theme folder, which you can also edit by hand:

{ "OP1": { "title": "Yuusha", "artists": ["YOASOBI"], "episodes": "1-16" }, "ED1-TV": { "title": "bliss", "artists": "milet", "episodes": "1", "spoiler": false }, "Season 2/OP1": { "title": "lulu.", "artists": ["Mrs. GREEN APPLE"] } }

If a theme lands in the wrong season, pick the right one with the Season dropdown in the editor, or type its AniDB id.

2. The file name

The code, then the title, then the artists separated by commas or &, then the episodes in square brackets if you like:

OP1 - Yuusha - YOASOBI [1-16].webm ED1-TV - bliss - milet.ogg

3. AnimeThemes.moe

Anything you haven't set yourself is looked up on AnimeThemes.moe, a community project. The lookup works from the AniDB ids on your shows and seasons; Shokofin sets them for you, and AniList, MyAnimeList and Kitsu ids work too. A show with no id at all is looked up by its title, and the editor labels those matches so you can check them.

  • Lookups are batched, spaced out and remembered for two weeks, to keep the load off AnimeThemes' servers. Shows AnimeThemes doesn't have yet are checked again after a few days.
  • The plugin never downloads video or audio from AnimeThemes. You supply the files.
  • To turn off title matching, untick Match shows by title when they have no ID. To never contact AnimeThemes at all, untick Look up song, artists and episodes on AnimeThemes.moe. Everything else keeps working, and you can fill in details with the editor.

Aster and its plugins aren't affiliated with or endorsed by AnimeThemes.

Cut missing themes from your episodes

Missing an opening or ending? The plugin can cut it out of your own episodes, using their chapter markers. Nothing is ever cut without you asking, and every clip waits for your approval.

  1. On the Setup tab, tick the libraries to search under Libraries to search. None are searched until you do.
  2. Press Look for clips now, or run Cut OP/ED clips from chapters in Scheduled Tasks.
  3. For each opening and ending a season should have but doesn't, the plugin finds an episode with a matching chapter and cuts that chapter out as a clip.
  4. Review the clips on the Review tab, then press Add to library.

Which chapters count

Looking forChapter namesLength
OpeningOP or Opening, with an optional number like OP230 to 200 seconds
EndingED or Ending, and also Credits, End Credits, Outro or Closing30 to 200 seconds; 30 to 150 for the extra names

Intro and Preview chapters are ignored on purpose, because they usually mean something else.

Reviewing clips

The Review tab groups clips by show, and plays each one beside what AnimeThemes says it should be. Click a clip, then use:

KeyWhat it does
A ApproveMoves the clip into your themes folder as an ordinary theme. Check the number in the row's number box first: clips are cut as OP1 or ED1 unless AnimeThemes or the chapter name says otherwise.
R RejectDeletes the clip, and that slot isn't cut again until you choose Forget rejections.
T Try anotherFor clips with credits or text over them: deletes the clip and cuts the same theme from the next usable episode. When there are none left, it tells you, and you can add the file yourself.
P PreviewPlays the clip.
Arrow keysMove between clips. Approve all and Reject all work on a whole show.

When you're done, press Add to library in the bar at the bottom of the page. It adds the whole batch in one go. It's never pressed for you, because it looks up song details on AnimeThemes.

Same opening or a different one? Once you approve a clip, later clips from the same show are compared with its length and marked "possibly the same OP" or "probably a different OP". Treat that as a hint, not an answer: different songs can be the same length.

Swap in a better version

Found a better copy of an opening, such as a creditless one? Put it in the show's folder in place of the old file, in any supported format. Then press Rescan files on that show in the Library tab.

The plugin picks up the new file and makes a playable copy if it needs one. The file you replaced goes into an _originals folder next to it: nothing is deleted.

Your themes as Jellyfin libraries

Want to listen to your theme songs like any other music? On the Setup tab, turn on Publish the themes as Jellyfin libraries, choose a folder for them, and press Save and create the libraries. The plugin adds two libraries and keeps them up to date:

  • Anime Openings & Endings (music videos): every theme with a video, with its song details and artwork. It takes no extra space.
  • Anime Theme Songs (music): every theme's song, with an album per show.

Playlists, favourites, search and parental controls then work as they do for anything else. Spoiler and NSFW themes are tagged, and NSFW videos get an age rating you choose (NC-17 unless you change it), so parental controls apply to them too.

The folder has to be outside your themes folder and every other library. Don't change the files in it by hand: the plugin overwrites them.

Watching in Aster

Open any episode and choose Watch OP or Watch ED. Aster plays the theme that aired with that episode, so when a show changes openings halfway through a season, Aster changes with it. If a theme has a full-length song or a music video, you can switch to that version too.

Themes flagged as spoilers or NSFW are handled with care.

Troubleshooting

A show's themes don't show up.

Check the Setup tab after a scan. If the show's folder is listed as not matching any show, its name doesn't match the show's folder in your library. Rename it to match exactly, then press Save and scan now. Also check the files start with OP or ED, and the themes folder is outside your libraries.

A theme has no song title or artist.

AnimeThemes may not have that show yet: newer and lesser-known shows are often added later, and the plugin checks again after a few days. It also needs an AniDB, AniList, MyAnimeList or Kitsu id on the show. In the meantime, fill in the details in the editor on the Library tab, or in the file name.

A theme plays on the wrong episodes, or in the wrong season.

Open it in the editor on the Library tab, which says how its season was chosen. Pick the right one with the Season dropdown, or move the file into that season's Season N or anidb- folder. To set which episodes it plays in, edit its episode range.

A new theme won't play yet.

If it's a format Apple devices can't play, like WebM, the plugin is still making a playable copy. That takes about 15 seconds for a 90-second opening, one file at a time, so a big batch can take a while.

The editor won't save.

Jellyfin needs permission to write to your themes folder. If it runs in Docker, check that the folder isn't mounted read-only.

Look for clips now doesn't find anything.

Make sure you ticked at least one library under Libraries to search, and that your episodes have chapters named like the ones in the table above. Episodes without chapter markers can't be cut.
